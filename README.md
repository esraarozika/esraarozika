🎓 Master’s Thesis

Model-Driven Management of Containerized Real-Time Applications

Developed a model-driven configuration and management approach for containerized TSN-capable end stations.

The implementation integrates Docker with YANG data modeling and NETCONF-based configuration management using Sysrepo and Netopeer2.

Key contributions include:

* Designing YANG data models for application and container management.
* Implementing NETCONF-based configuration workflows.
* Integrating Sysrepo and Netopeer2 for configuration management.
* Automating Docker container creation, deployment, and lifecycle management.
* Supporting dynamic runtime configuration of containerized applications.
* Implementing configuration reconciliation and self-healing mechanisms.
* Managing network parameters and application-specific configurations.

🔬 Research Project – Seal Tracking

Worked on an AI-based research project focused on seal tracking using deep learning models and visual feature representations.
